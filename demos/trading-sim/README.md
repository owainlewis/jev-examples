# Jev trading simulator

A local BTC-USD simulator with Coinbase prices, real Jev decisions, and a virtual $10,000 portfolio. There is no real order API, exchange credential, or wallet integration.

## Run

Requires uv, Python 3.11+, and Node 22.12+ or 24. From this folder:

```bash
uv sync --locked
cp .env.example .env
```

Add your TypeSafe key to `.env` as `TYPESAFE_API_KEY`. Coinbase's public market-data feed needs no key. Then:

```bash
cd frontend
npm ci
npm run build
cd ..
uv run uvicorn backend.app:app --host 127.0.0.1 --port 8001
```

Open http://127.0.0.1:8001. Start simulation enables real, billable Jev calls. Pause stops decisions and cancels a pending fill. Switching price sources resets the portfolio after confirmation.

Live market uses Coinbase Exchange's public BTC-USD ticker. Synthetic replay produces deterministic example prices; it is not historical data. Both modes use real Jev. Prices continue to arrive while paused. The engine collects 30 quotes before the first call, then waits 15 seconds after each call before considering another.

## Trading policy

Python calculates fast and slow averages over 5 and 30 quotes and a recent percentage change. Jev Choice selects buy, hold, or sell against an experimental momentum policy. This is a demonstration of classification, not a validated price forecast. Quote-based windows cover variable durations in live mode.

The ledger allows one long position, with up to $1,000 including entry fees. There is no borrowing, leverage, short selling, or real execution. A selected probability below 75% does not create an order. Jev failure pauses the simulation. A stale feed pauses trading; resume after fresh data arrives.

Action probabilities are not probabilities of profit. No explanation is generated by Jev; the interface shows the fixed policy, actual probabilities, and the code's execution result.

## Accounting

- Buy at the next ask after the Jev decision, plus 0.05% assumed slippage.
- Sell at the next bid after the decision, minus 0.05% assumed slippage.
- Charge 0.10% fees per side. These are demo assumptions, not Coinbase account fee rates.
- Cancel a pending order if no fresh quote arrives within 10 seconds.
- Realized profit includes the entry cost and both sides' fees.
- Portfolio equity and unrealized profit estimate liquidation at the current bid after exit slippage and fees.
- Maximum drawdown measures the largest decline in portfolio equity while running.
- The buy-and-hold comparison invests the whole $10,000 at the first quote after start, with the same costs. Its exposure differs from the strategy's $1,000 position.

Simulated fills assume sufficient liquidity and do not model queue position or market impact. These results are estimates, not what real orders would necessarily earn.

## Storage and limits

Snapshots are stored locally in `instance/trades.sqlite3`, ignored by Git. The last 500 decision/fill/reset snapshots are retained. A server restart starts a fresh paused session; older snapshots remain for inspection. The UI retains 600 price points and the most recent 100 decision events. API keys remain on the server. Jev receives computed market features and virtual portfolio state, not credentials.

Keep the server on loopback. Controls accept local origins only. This demo has no user authentication and is not intended as a hosted service.
