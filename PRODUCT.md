# Jev tutorial examples

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Python developers following Owain's YouTube tutorial. The presenter creates tickets and inspects Jev's decisions on screen.

## Product purpose

Teach Noul, Choice, and Score, then use them in a local support desk and an email classification command for coding agents.

## Stack

Python is requested. Implementation choice: Flask, server-rendered HTML, and SQLite keep the application small enough to explain.

## Capabilities and constraints

Create tickets, classify with Jev, inspect probabilities, filter the inbox, and save human corrections. Save tickets before calling the API so a failed request does not lose the ticket. This is a local tutorial app, not a hosted help desk. Synthetic examples only in the repository. Email definitions remain provisional and configurable. No mailbox writes or refund execution.

## Operating context

Desktop screen recording and local browser use. Assumed visual direction: a quiet, readable inbox with a ticket detail panel. No existing brand assets or visual identity were supplied. The user's instruction to proceed delegates routine implementation choices.
